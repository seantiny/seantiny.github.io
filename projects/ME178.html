ME178 — Research

Flight Cost Analysis using ML

Organization

UC Berkeley — ME178

Role

Researcher

Timeline

2024

Software

Python, scikit-learn

Skills

Machine Learning, Regression, Data Cleaning

01

Overview

We developed a machine learning model to predict flight prices and identify factors that influence ticket costs. Using a dataset of over 300,000 flight records, we processed flight information including airline, class, number of stops, duration, and days before departure.

We compared several machine learning approaches, including LASSO regression, Random Forests, and neural networks. The dataset was cleaned, numerical features were scaled, and categorical variables were one-hot encoded before training the models. We tested different model parameters and compared their performance using R².

03

Results

The best LASSO model achieved an R² of 0.9080, while the best neural network reached 0.9478. Our best-performing model was a Random Forest with 60 estimators and a maximum depth of 12, achieving an R² of 0.9554. The results showed that nonlinear models were better able to capture the relationships between flight characteristics and ticket prices.
