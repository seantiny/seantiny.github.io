Overview

Collaborated on the full-stack development of a Chrome extension designed to reduce procrastination for high school students using the Pomodoro technique. The extension manages timed work and break intervals to improve focus and productivity.

Led back-end development, integrating the Chrome.storage API to implement persistent client-side data storage that efficiently manages user preferences and session states without relying on external backend services. Supported front-end development using JavaScript to build a responsive and intuitive user interface that enables seamless session control and real-time feedback.

Pomochromo is available on the Chrome Web Store.
